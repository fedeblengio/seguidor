# Seguidor

Plataforma simple para que negocios chicos y medianos ordenen clientes, consultas, presupuestos y seguimientos.

## Quick Start

```bash
docker compose up -d
```

- Frontend: http://localhost:5173
- API: http://localhost:8000

## Features

- Alta y gestion de clientes/prospectos
- Estados comerciales (nuevo, contactado, presupuesto enviado, etc.)
- Notas internas e historial
- Recordatorios de seguimiento
- Plantillas de mensajes
- Boton directo a WhatsApp con mensaje prearmado
- Dashboard con metricas basicas
